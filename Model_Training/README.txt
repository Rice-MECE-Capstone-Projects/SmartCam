# Indoor Obstacle Detection (YOLOv8) 🚀

This repository contains an end-to-end pipeline for training a YOLOv8 custom object detection model to identify indoor obstacles (e.g., chairs, doors, people, stairs). It includes everything from raw data processing and data augmentation to model training and verification, heavily optimized for subsequent deployment on edge devices like the Jetson Nano.

## 📂 Repository Structure

Below is an overview of the key files and directories in this project:

### 📁 Directories
* `dataset_prepared/` - The final split and augmented dataset ready for YOLOv8 training (generated by `prepare_dataset.py`).
* `experiment_dataset/` - An experimental dataset directory using hard-linked short IDs to bypass Windows path limits (generated by `experiment_rename.py`).
* `runs_0423/` / `runs_backup_0422/` - YOLOv8 training outputs, including model weights, metrics (PR curves, confusion matrices), and training logs.
* `.vscode/` - Local Visual Studio Code workspace settings.

### 📄 Core Python Scripts
* **`prepare_dataset.py`** Full data pipeline that splits raw data into Train/Val/Test sets, applies heavy augmentation (Mosaic, HSV, blur, flip), and renames files to bypass the Windows 260-character `MAX_PATH` limit.
* **`experiment_rename.py`** A utility script that creates short-path hard links for your images and labels, ensuring zero extra disk space is used while preventing path-length errors during training.
* **`visualize_labels.py`** A visual verification tool. It randomly samples images from the dataset and draws the YOLO bounding boxes and class names to ensure data integrity before training.
* **`train_point.py`** The core training script for YOLOv8. It configures the dataset, handles auto-resume from the latest checkpoint, and outputs a detailed performance summary.
* **`rename_test_lab.py`** Utility script for batch processing or modifying label txt files.

### 📦 Configuration & Weights
* `data.yaml` / `data_exp.yaml` - YOLOv8 dataset configuration files defining paths and the 7 indoor classes.
* `yolov8n.pt` / `yolov8s.pt` / `yolo26n.pt` - Pre-trained Ultralytics weights used as the starting point for Transfer Learning.
* `best.pt` - The fully trained, fine-tuned custom weights optimized for our indoor dataset.

## 🛠️ Pipeline / Quick Start

**1. Prepare & Augment the Dataset**
Run the preparation script to split the data, apply augmentations, and bypass Windows path limits.
```bash
python prepare_dataset.py
(Optional) 1b. Fix Path Lengths explicitly
If you only need to fix Windows path lengths without full augmentation:

Bash
python experiment_rename.py
2. Verify Annotations
Make sure your bounding boxes are correct before spending hours training.

Bash
python visualize_labels.py
Check the newly created annotation_check folder for visual results.

3. Train the Model
Start the training process using the YOLOv8 small/nano architecture.

Bash
python train_point.py
4. Edge Deployment (Jetson Nano)
Once training is complete, the best.pt file can be exported to a .engine (TensorRT) format and deployed onto a Jetson device using a ROS2 node (see the corresponding ROS2 Jetson repository).
